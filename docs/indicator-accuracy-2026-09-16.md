# FlowScope 指标在 2026-09-16 行情中的准确度评估

评估时间：2026-09-16 10:10（北京时间）。数据源：正在运行的 `http://127.0.0.1:8000` 的
`/api/history` 实时快照（`KQ.m@SHFE.fu` 燃油主连）。

结论先说：**在今天这段行情里，只有「LSMA×CRVOL」的超买超卖过滤（WT2）表现出可复现的方向准确度；
Delta / CRVOL / CVD / LSMA 波的方向信号主要是"跟随了当天的单边上涨"，而不是预测能力——
把它们拿到上一个交易日（09-15）对照，符号会整体翻过来。**

---

## 1. 评估对象与方法

### 1.1 指标复算与校验

指标没有另写一套实现，而是把 `static/app.js` 里的 `derive()` / `deriveLw()` / `levelOf()` 逐字移植到
`docs/indicator_recompute.js`，用 Node 跑同一份 API 数据。校验结果：

| 校验项 | 结果 |
| --- | --- |
| `delta` 与后端返回逐根对比 | 最大误差 **0.000000** |
| `cvd` 与后端累计对比（含基准） | 最大误差 **0.000000** |

即复算值与页面读数完全一致，后面的统计结果就是页面指标的统计结果。

### 1.2 准确度怎么量

- **前视收益**：`close[i] → close[i+h]`，h ∈ {1, 3, 6, 12, 30} 根。信号只用 i 及之前的信息，无未来函数。
- **命中率**：`sign(前视收益) == 信号方向` 的比例。
- **同向基准（关键）**：今天日盘是单边上涨，任何"看涨"信号都会自动显得准。所以每个信号都比
  **与它同阴阳类别的全部 bar** 在同一 h 上的命中率。只有**超出同向基准的部分（lift）**才算指标的信息量。
- **显著性**：块 bootstrap（块长 = h，4000 次），对重叠样本和自相关稳健。
- **跨窗口对照**：同一批指标、同一套代码，再跑 09-15 日盘（上一个交易日），看符号是否稳定。

### 1.3 样本与已知局限

| 项目 | 今日日盘 (09-16) | 对照日盘 (09-15) |
| --- | --- | --- |
| 窗口 | 09:00 – 10:04 | 09:09 – 14:59 |
| 10s bar 数 | 385 | 不在 800 根窗口内 |
| 30s bar 数 | 129 | 431 |
| 价格 | 4529 → 4571（+0.93%，10s）/ 4528 → 4571（+0.95%，30s） | 4442 → 4476（+0.77%） |
| 指标预热 | 用前夜 21:50–22:59 共 69 分钟，`smalen=300` 刚好满足 | 更有余量 |

**必须说明的三个局限：**

1. **窗口被 800 根上限截断**。服务端只向 `/api/history` 返回最近 800 根 bar，10s 口径下只有 2.2 小时，
   于是今天的日盘只覆盖到 **10:04**，不是全天。想评估完整交易日需要走项目自己的历史 CSV 或加长快照接口。
2. **p 值只在"本窗口内可交换"这一假设下成立**。单窗口、强趋势、信号又在时间上聚集，
   `p<0.05` 很容易出现；真正有信息量的是**跨窗口符号是否一致**，而不是单窗口的星号。
3. **两套量的口径本身不干净**（见下表），tick 口径的日盘 bar 里 97% 标记为 `partial`。

### 1.4 数据质量（今日日盘 385 根）

| 口径 | 覆盖标记 | 买或卖为 0 的 bar | corr(delta, 本根涨跌) | corr(CVD 变化, 价格变化) |
| --- | --- | --- | --- | --- |
| 10s K线口径 ltf=5 | `complete` 384 / `partial` 1 | 258 根（**67%**，全是十字线：`close == open`） | **0.833** | 0.505 |
| 10s tick 口径 Lee-Ready | `complete` 10 / `partial` 375 | 0 根 | **0.560** | 0.256 |

- K 线口径那 67% 的"单边 bar"不是数据坏了，而是 `close > open` 的归类规则本身：10 秒尺度上十字线极多，
  这些 bar 的 volume 全部落在"既不算买也不算卖"里（与 README 第 41、65 行的说明一致）。
- K 线口径 0.833 的高相关是**定义使然**（delta 由阴阳定义），不能当成预测能力；tick 口径 0.560 才是
  Lee-Ready 判向与真实涨跌的实际吻合度。
- tick 口径在 10s 尺度上 375/385 是 `partial`（快照区间量无法与主周期成交量逐根核对），
  今天只有 10 根通过核对。**这是当前采集环境最大的精度瓶颈**，与判向算法无关。

## 3. 口径敏感性：换成 tick 判向（n=385，Lee-Ready）

同一批信号换成 tick 口径（`ltf=0`）后，绝大多数指标读数**完全不变**（RVOL / LSMA / CRVOL 与成交量有关，
与判向无关）；只有 Delta 类信号有变化：

| 信号 | K线口径 ltf=5 | tick 口径 Lee-Ready |
| --- | --- | --- |
| Delta买脉冲≥1.5（+6根） | 57.0% | 55.6% |
| Delta买脉冲≥2.5（+6根） | 63.8% | 54.4% |
| Delta买脉冲≥2.5（+30根） | 60.0% | 53.7% |
| CVD 3根↑（+30根） | 57.7% | 57.7% |
| CVD 3根↓（+30根） | 33.9% | 33.9% |

**tick 口径的 Delta 脉冲一致性更差**：`Delta买脉冲≥2.5` 在 6 根上从 63.8% 掉到 54.4%（基准 53.5%），
几乎等于没有信息。原因是 tick 口径的日盘 bar 只有 10/385 通过成交量核对、97% 是 `partial`，
估算量本身带噪声（corr 0.560 vs K 线的 0.833）。**在目前这个采集条件下，用 tick 口径的 Delta 做短周期方向判断并不可靠。**

## 4. 关键对照：同一批指标跑 09-15 日盘（30s，n=431）

这是判断"到底有没有预测能力"的决定性一步。同一段代码、同一套阈值，只换交易日：

| 信号（+30根） | 09-16 今日 lift | 09-15 对照 lift | 是否稳定 |
| --- | --- | --- | --- |
| **WT2<20 超卖→看涨** | **+15.8pp** | **+18.7pp** | ✅ **两日同号，唯一稳定项** |
| Delta买脉冲≥1.5 | −2.6pp | +5.3pp | ❌ 翻转 |
| Delta买脉冲≥2.5 | ±0.0pp | +0.4pp | ❌ 无信息 |
| CRVOL 3根↑ | −2.2pp | +0.7pp | ❌ 翻转 |
| CVD 3根↑ | −4.8pp | +3.2pp | ❌ 翻转 |
| LSMA波↑ | −7.4pp | +8.6pp | ❌ 翻转 |
| LSMA↑&斜率>0 | −4.0pp | +1.3pp | ❌ 翻转 |
| CRVOL 3根↓ | +26.1pp | −6.6pp | ❌ 翻转 |
| CVD 3根↓ | +29.4pp | −5.4pp | ❌ 翻转 |
| LSMA波↓ | +31.4pp | −13.0pp | ❌ 翻转 |
| WT2>80 超买→看跌 | +19.7pp | −37.3pp | ❌ 翻转 |

> lift = 信号方向命中率 − 同向基准。对看跌信号，**正的 lift 表示看跌信号反而跑赢阴线基准**——
> 也就是在看涨日"失效"（如 09-16 的 CVD 3根↓ 命中率只有 30.6%，基准 60.0%，lift = −29.4pp，
> 换句话说它的反向"上涨判定"赢了 29.4pp）。两天的符号恰好全部镜像，正说明这些信号是当日趋势的投影。

**09-15 那天整体是下跌/震荡日**（阳线基准 37.3%、阴线基准 46.3%），于是所有看涨信号都跑输、看跌信号都跑赢——
与 09-16 完全镜像。这正好证明第 2 节里那些"有效/失效"大部分是**当日趋势的投影**，而不是指标本身的稳定 edge。

**例外只有一个：WT2<20。** 无论 09-16（上涨日）还是 09-15（弱势日），它的 lift 都是正且都在 +15pp 以上，
是这次评估里唯一通过跨日检验的信号。

## 5. 结论与建议

1. **今天这段行情里，指标的方向准确度排序是：WT2 超卖过滤 ≫ Delta 脉冲（仅 1–2 分钟）> 其余全部 ≈ 无效。**
2. **LSMA 波 / CRVOL / CVD 的方向信号不具备跨日稳定性**，它们更接近"趋势的温度计"（同步描述当下强弱），
   不要当反转或突破的触发条件用。这与 README 里"30 秒尺度放大 K 线方向噪声、方向判断请用 tick 判向"的
   结论方向一致，但更进一步：**即使是 tick 判向，其派生指标的方向信息在今天也没有跨日稳定性。**
3. **RVOL 阈值本身不构成方向信号**——它只度量"放量"，方向仍由 K 线阴阳决定，而 10s 尺度上 67% 是十字线。
   今天 RVOL≥1.5 阳线 29 根、阴线 19 根，30 根后命中率 64.3% vs 38.5%，差异几乎全部来自当日上涨。
4. **优先修数据而不是调参数**：tick 口径 375/385 的 `partial` 覆盖率，是所有短周期量价指标的精度上限。
   在它改善之前，任何 Delta/CVD 参数的"优化"都是在拟合估算噪声。
5. 想得到可信的指标准确度结论，下一步应做的是：**把评估挪到完整交易日 + 多日样本**（需要绕过 800 根快照上限，
   例如让评估直接读落盘历史或临时提高快照根数），并且**只用通过成交量核对的 bar** 做统计。
