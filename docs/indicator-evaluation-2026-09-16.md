**把指标变成可检验规则**

项目目前主要提供图形显示，没有预设的自动买卖策略。以下是为本次评估固定的解释规则，特别是“反转”和“共振”均不代表项目已实现的交易信号。

| 指标/规则 | 看涨条件；看跌条件 |
| --- | --- |
| Delta / Buy-Sell Volume | 新算法 Delta > 0；Delta < 0。买卖量强弱与 Delta 属于同一信息，不重复当作独立指标。 |
| 强 Delta | 上述方向且正/负 Delta 各自相对20根均值的比例严格 > 2.25，等于项目 RELATIVE 第一档门槛。 |
| CVD | 当前 CVD 减去5分钟前 CVD > 0；< 0。不用具有任意累计起点的 CVD 绝对正负值。 |
| CRVOL | 项目已有的10根线性回归末值之差，即 `crvolSlope` > 0；< 0。 |
| LSMA 顺势 | 项目 `wave` 比上一根上升；下降。 |
| LSMA 极值反转 | 面板低位点对应的 `wt2 < 20` 看涨，高位点对应的 `wt2 > 80` 看跌。这里使用实际控制圆点的 wt2，并非把 wave 的阈值误当成圆点。 |
| LSMA×CRVOL 共振 | LSMA斜率与CRVOL斜率同向，且 RVOL≥1.5，沿该方向。此组合规则是本次评估定义的。 |
| RVOL 放量顺势 | RVOL≥1.5，沿 K 线实体方向；十字线不发信号。 |
| EMA21/55 | EMA21 > EMA55；EMA21 < EMA55。 |

**两个影响解释的重要实现口径**

1. **CRVOL 把十字线全部计为负值。** [实际累加位置](C:/Works/Futures/FlowScope/static/app.js:450) 是收盘高于开盘加RVOL，其余减RVOL。今天10秒样本中59根十字线贡献 **−48.61**，整段CRVOL净变化 **−8.54**；若仅在算术上把十字线改为中性，净变化会是 **+40.07**。本次没有修改指标，这个对照只说明负漂移来源，不能据此认定价格上涨时CRVOL就必须上涨，也不能把负值直接等同于真实主动卖盘。30秒周期同一早盘CRVOL反而增加8.99，说明周期和十字线口径对它影响很大。
2. **新旧 Delta 的同步解释能力与预测能力是两件事。** 排除平实体和零Delta后，新算法与当根K线方向一致率为64.1%（10秒），旧算法为26.9%；这是同根相关性，不是真实成交方向标签，也不是未来命中率。对应未来3分钟的新算法只有48.0%，旧算法49.0%，不能从旧算法略高的事后数值反推出旧算法更准确。
