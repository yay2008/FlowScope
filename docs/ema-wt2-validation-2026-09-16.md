- 历史检查也是事后研究，不宣称是真正未见过行情的样本外验证。本次没有按最高胜率反复寻找参数。

**把“开口/缠绕”变成可计算条件**

首先固定四条均线的严格口径：EMA21 > EMA55 > EMA100 > EMA200，并且每条都高于60秒前，判为上涨；全部反向判为下跌。均线带宽不超过ATR20时判为窄带震荡，其余判为过渡；当前数据不足以计算同一交易时段内的斜率时，也归为过渡。ATR20是20根真实波幅的简单平均，隔夜和休市跳空不计入该bar的真实波幅。

这个严格口径在今天没有出现“上涨＋超卖”和“下跌＋超买”事件：WT2进入反向极值时，短EMA往往已不满足同向条件。因此又记录了一个**补充性、探索性的慢趋势口径**，没有删除严格版本，也没有把补充版本冒充原始预设规则：

| 背景 | 本报告慢趋势口径 |
| --- | --- |
| 上涨 | EMA100 > EMA200；两者都高于60秒前；间距 > 0.5×ATR20。EMA21/55允许暂时回调。 |
| 下跌 | EMA100 < EMA200；两者都低于60秒前；间距 > 0.5×ATR20。 |
| 窄带震荡 | EMA100与EMA200的间距 ≤ 0.5×ATR20。 |
| 过渡 | 不满足以上条件，或缺少同交易时段内的斜率。 |

下面主表使用慢趋势口径。这里的“窄带震荡”只是均线接近的量化代理，**不等价于所有人目测的四线缠绕**。不同EMA组合和阈值的结果全部保留，结论必须连同定义阅读。
